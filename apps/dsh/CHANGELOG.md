# Changelog

此文件记录 DSH for fnOS 面向用户的发布变更。每次发布都必须新增与应用版本一致的 `## [版本]` 条目；GitHub Release 会直接使用该条目的内容。

## [1.1.2]

### Fixed

- 修复 DSH 新版使用相对路径跳转启动令牌时，被误判为启动检查超时的问题。
- 修复状态岛打开版本选择列表后，状态轮询导致列表不断刷新的问题。
- 修复内置终端因应用账户的 `nologin` shell 而无法打开的问题；DSH 子进程使用 `/bin/sh` 作为默认 shell。

### Build

- 本地打包前自动重新构建应用，避免将旧代码打入 FPK。

## [1.1.1]

### Fixed

- 优化手机端顶部状态岛布局，使其按内容收缩并水平居中，避免遮挡 DSH 标识。
- 修复手机端状态岛居中后，版本与目录菜单定位到页面顶部并被截断的问题。

### Documentation

- 在应用说明中增加桌面端与移动端界面预览。

## [1.1.0]

### Added

- 支持按飞牛用户独立运行 DSH；每位用户选择自己的工作目录，配置、会话、插件和工作区相互独立。
- 支持将飞牛额外授权目录显示在 DSH 工作目录内，并允许用户在状态岛中管理个人运行版本、重启和目录授权。
- 管理员可统一下载、删除和设置默认 DSH 版本，并查看、手动关闭所有运行中的用户服务；增加空闲自动关闭时间设置，默认 600 秒。
- 首次安装自动下载 latest；首个完成工作目录授权的管理员会自动启动 DSH。
- 状态岛、启动页和设置页适配飞牛桌面端与手机端访问。

### Fixed

- 修复旧 profile 或依赖目录权限异常导致 dsh-market 无法安装的问题；应用会保留旧 profile 备份并重建可用的官方 profile。
- 修复启动页在已选择工作目录或普通用户场景下错误显示工作目录选择和设置入口的问题。

## [1.0.2]

### Added

- 支持通过飞牛统一网关的 `/app/dsh-for-fnos/dsh/` 路径访问 DSH，无需额外开放 DSH 端口。

### Fixed

- 插件变更后仅在 dsh-market 连续确认安装操作已结束时自动重启；状态查询暂时失败或出现新的文件变更会继续等待，避免中断更新。

## [1.0.1]

### Fixed

- 修复通过 dsh-market 更新插件时，管理器过早重启 DSH，导致更新请求提示“DSH 连接暂时不可用”的问题。

## [1.0.0]

### Added

- 支持在 fnOS 内下载、校验、保留、启用和回退多个 DSH 版本，本地最多保留 5 个已完成版本。
- 支持 `latest`、`alpha`、`beta`、`next` 更新标签、可选 npm 源，以及首次自动安装 dsh-market。
- 将 DSH 与设置页整合到同一应用窗口，并提供统一状态岛、重启和设置入口。
- 将 DSH 工作区、配置、插件和会话保存在飞牛共享目录，方便备份和维护。
- 保留官方 DSH profile 与插件 API，代理透传插件资源、HTTP API、SSE 和 WebSocket。
- DSH 应用图标、原生入口和双架构 FPK 打包流程已适配 fnOS。
