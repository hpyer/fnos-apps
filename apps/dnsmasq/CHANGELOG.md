# Changelog

此文件记录 Dnsmasq for fnOS 面向用户的发布变更。每次发布都必须新增与应用版本一致的 `## [版本]` 条目；GitHub Release 会直接使用该条目的内容。

## [1.0.0]

首个正式版本，提供 x86_64 与 ARM64 安装包。

### Added

- 以专用应用用户运行 dnsmasq 2.93，固定使用 53 端口；内置运行时基于 Debian 12 构建，构建时校验大小、SHA-256 与 ELF 架构。
- 概览、设置、解析记录三个页面，适配 1100×596 桌面窗口与移动端底部导航；诊断收在概览中，可查看运行权限、53 端口能力、运行平台、二进制、hosts 状态、生成的配置和最近日志。
- DNS-only 服务：可配置监听地址、显式上游 DNS、缓存大小、查询日志和自动启动；不配置 DHCP，不修改路由、NAT 或 `/etc/resolv.conf`。
- 精确记录与后缀记录；精确记录支持同一域名的多个 IPv4/IPv6 地址，后缀记录匹配该域名及其子域名。
- 可选的 NAS hosts 同步：把精确记录和后缀记录域名写入 `/etc/hosts` 标记块，修改或删除记录后自动更新，关闭或卸载时移除；不影响其他 hosts 内容、容器 hosts、Clash 的 DNS 与 TUN。
- 管理员授权：首次绑定 53 端口或开启 hosts 同步时输入一次 NAS 管理员密码，密码经临时 ECDH 信道加密提交；root helper 只安装最小 sudoers，应用与 dnsmasq 仍以应用用户运行，升级或启动时自动恢复 `CAP_NET_BIND_SERVICE`。
- 概览页与诊断显示 dnsmasq 版本，运行后以启动横幅中的实际版本为准。
- 启动失败时给出可操作提示，覆盖 53 端口被占用、监听地址不属于本机、缺少能力等情况，并保留 dnsmasq 原始 stderr。
- 卸载向导提供「保留数据（默认）/删除全部应用数据」，删除时只清理本应用数据并校验路径。

### Fixed

- 修复 socket 模式下网关请求被误判为非管理员并返回 403 的问题。
- 修复安装后页面缺少样式表和脚本引用、界面以无样式 HTML 呈现的问题。
- 修复升级后文件能力丢失、helper 路径不匹配，以及启动失败只显示退出状态的问题。
- 修复网关用户名被 `/etc/passwd` 中同 UID 账户覆盖的问题。
- 修复应用标识与系统已有 dnsmasq 用户冲突、安装端口向导和生命周期脚本阻塞安装的问题。

### Compatibility

- 依赖飞牛 Node.js 24，支持 Linux x86_64 与 ARM64，需要可用的 53 端口和文件 capability 支持。
- 运行时基于 Debian 12（glibc 2.36）构建，与 fnOS 底座一致。
- 应用不接管系统 DNS：NAS 本机系统解析需开启 hosts 同步，否则请用 `dig @127.0.0.1` 等方式显式查询。
