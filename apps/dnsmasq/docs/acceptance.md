# Dnsmasq fnOS 验收清单

- [ ] x86_64 和 arm64 FPK 中只包含对应架构的 dnsmasq 二进制，版本和 SHA-256 已记录。
- [ ] 安装后 helper 为 root 所有、不可写，sudoers 只允许 `dnsmasq-caps apply`。
- [ ] 安装脚本以应用用户执行时，首次启动显示可操作的 53 端口权限提示；输入管理员密码完成初始化后可直接启动，刷新后不再要求授权。
- [ ] 管理员密码只经加密信道提交，不出现在界面、日志、进程参数或存储中。
- [ ] 升级替换 dnsmasq 二进制后，能力自动恢复；停止/重启不残留 pid 文件或进程。
- [ ] 53 端口被占用、缺少能力、监听地址不属于本机时，界面显示对应原因，而不是只显示退出状态。
- [ ] 管理页面在 1100×596、移动窄屏和普通桌面尺寸可用，无横向溢出；移动端使用底部导航。
- [ ] 概览默认只显示一个「运行诊断」按钮；展开后诊断信息在 1100×596 内可读。
- [ ] 监听 127.0.0.1 与指定 LAN 地址；局域网客户端可查询，未配置 DHCP、路由、NAT。
- [ ] 精确记录、后缀记录、缓存、上游 DNS 和查询日志设置生效；关闭查询日志时不写入查询记录。
- [ ] 开启 NAS hosts 同步后，精确记录和同一域名的多个地址都能被本机 `getent hosts` 解析；后缀记录至少能解析域名本身。
- [ ] 后缀记录的子域名不会被 hosts 匹配，界面和文档已说明该限制。
- [ ] 修改/删除记录后 hosts 标记块自动更新且不重复；关闭开关后标记块移除，`/etc/hosts` 其他内容保持不变。
- [ ] 开启 hosts 同步前后，Clash 的 TUN、系统代理和 DNS 配置不被修改，Clash 运行的域名分流不受影响；容器内 `/etc/hosts` 不变。
- [ ] 卸载时即使选择保留应用数据，`/etc/hosts` 标记块也被移除；重复卸载不报错。
- [ ] 启动、停止、重启、升级后配置保持；异常退出不留下错误 pid 状态。
- [ ] 卸载向导默认保留数据；明确删除时只删除本应用专属目录。
