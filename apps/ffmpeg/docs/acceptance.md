# 验收

## 本机自动检查

`pnpm test` 覆盖架构与资产过滤、固定构建选择、独立组件 SHA256/大小/重定向校验、安全 ZIP/tar 解压、默认仅下载 ffmpeg、当前版本补装与后续同步、选项持久化与取消、补装失败/版本不匹配/服务中断、历史版本启用及回滚补齐、旧 BtbN 兼容、组件提交日志恢复、文件改动和链接拒绝、操作互斥、umask 077、网关管理员鉴权、写请求校验、命令参数/标准输入/退出码透传，以及未安装 ffprobe 的提示与 127 退出码。Linux CI 额外运行真实 flock 的长任务切换及删除竞争测试；macOS 不具备 util-linux flock，此项跳过，不以模拟锁代替 Linux 并发验收。

`pnpm run pack ffmpeg --all` 生成 x86、arm 两个 FPK，检查 FPK 不包含 FFmpeg 二进制，包含两条可执行入口、图标、管理页及公共包运行代码。发布版本的说明维护在应用 `CHANGELOG.md`，不计入仅调整仓库工具的提交。

## fnOS 实机必测（待验收）

记录测试时 fnOS 版本、CPU 架构、内核、glibc、目标 GPU 及驱动版本，不记录完整环境变量或用户数据。

1. 安装 x86_64 / ARM64 各自的 FPK；核对包用户、网关管理员身份头、Socket 所有者及 0660。普通用户和绕过网关的请求不可访问管理接口。
2. 确认 `/usr/bin/xz`、`/usr/bin/flock` 存在；独立组件来源查询只请求 ffmpeg 元数据，默认安装只下载 ffmpeg ZIP。核对固定时间戳、版本、架构和 SHA256，完成解压与 PCM 自检。验证 ARM64 / x86_64 不会混装；硬件与 glibc 不兼容时清晰报错并清理暂存。模拟 HEAD 不可用、错误 SHA256、跨域重定向、断网和磁盘不足，确认下载被正确限制且当前版本不受影响。下载中途主动断开连接，检查重试计数、Range 续传或安全重下；持续失败最多重试 3 次，最终显示可读原因并清理残片，停止服务不继续重试。旧 BtbN 补装兼容路径另验证原始归档和 GitHub 资产域名限制。
3. 首次下载后命令仍提示未启用。启用后从 SSH、Xterm、普通用户、定时任务和另一个包用户调用 ffmpeg 绝对路径，确认父目录可遍历且可执行。ffprobe 未安装时显示安装提示并返回 127，管理页不显示可用。核对实际 PATH 优先级，保留已有系统 FFmpeg。
   勾选 ffprobe，确认只下载当前相同时间戳目录的 ffprobe，补装前后 ffmpeg 哈希、文件 inode 及 current 不变；组件版本一致且跨账户可执行。失败或中断不保存同步选项，重试或重启后可恢复。已有 ffprobe 不重复下载。保持勾选下载新版本时同步两组件，切换/回滚到缺失组件的历史版本时先补齐；目标补装失败则不切换。取消勾选保留已有组件，后续新版本只下载 ffmpeg，重启后选项保持。无当前版本时也能保存选项。
4. 安装和升级前分别放置受控的同名普通文件、他包软链、断链，确认安装失败且不覆盖。恢复本应用合法链接后可继续升级。确认资源创建与 `install_init` / `upgrade_init` 的实际顺序符合检查前提。
5. 启动长转码，下载并启用另一版本；旧任务持续执行，新调用使用新版本，两条工具成套切换。运行中旧版本删除被拒绝，任务结束后能删除；当前版本不能删除。
6. 切换后回滚，确认前一版本恢复且可再次切回；下载失败、错误 SHA256、自检失败、文件被改动、空间不足或断网不改变原生效指针。模拟管理服务停止并重启，暂存清理且已安装版本保留。
7. 通过全局命令验证管道输入、包含空格和特殊字符的参数、Ctrl-C、退出码与调用者身份；应用不提权、不额外记录媒体内容。
8. 停止管理应用，确认终端已启动命令不被杀死，并记录新调用是否仍可使用资源链接；升级 FPK 后版本列表和指针保留。卸载前结束命令，确认只清理本应用链接，数据保留/删除符合飞牛选项，不碰系统 FFmpeg。
9. 实际测试所需编解码器及代表性文件。Intel QSV / VAAPI、AMD、NVIDIA、ARM 硬件分别验证驱动与调用者权限；`-hwaccels` 只作为编译信息，不作为验收结果。
10. 管理页在桌面与窄屏中检查空状态、下载进度、网络错误、版本选择、启用/删除确认、回滚、构建信息、键盘焦点与较长构建名换行。

没有目标 NAS 的真实安装和以上记录，不得将本机测试或打包标记为实机验收通过。
