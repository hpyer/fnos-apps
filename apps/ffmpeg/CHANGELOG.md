# Changelog

## [0.1.0]

### Added

- 首次发布 FFmpeg for fnOS，提供 x86_64 与 ARM64 安装包，通过管理员页面下载和管理 FFmpeg；应用包不内置 FFmpeg 二进制。
- 提供全局 `ffmpeg` 命令及可选的 `ffprobe`，支持同一构建补装、同步安装和设置持久化。
- 支持多版本下载、手动启用、切换、回滚和删除；任务锁保护正在执行的命令，切换不影响已有任务。
- 从固定上游构建下载独立组件，验证 SHA256、文件大小、归档边界和设备架构，并在启用前执行自检。
- 下载中断后自动重试，优先使用 Range 续传；失败或取消时清理暂存并保留当前版本。
- 提供适配桌面和窄屏的管理界面、下载进度、操作通知、构建信息及应用更新提示。

### Compatibility

- 依赖飞牛 Node.js 24，管理页面仅向管理员开放；全局命令以调用者身份执行。
- 具体 fnOS 安装、跨账户调用、生命周期及硬件转码兼容性仍需目标 NAS 实机验证，本机测试与打包结果不代表实机验收通过。
