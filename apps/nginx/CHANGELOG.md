# 更新日志

## [1.1.1] - 2026-09-30

### 功能与调整

- 管理页检查应用自身的 GitHub Release；发现新版本时显示常驻 FPK 下载链接，安装仍由用户在飞牛应用中心手动完成。
- 稳定版与主线版的 Nginx 官方版本查询接入公共版本检查接口，保留现有的手动检查和下载校验流程。

### 修复

- 将应用版本信息打入 FPK 运行目录，避免启动时依赖包外的 manifest。

## [1.1.0] - 2026-09-30

### 功能与调整

- 应用包、管理服务和 Nginx 进程改为以 `nginx_for_fnos` 用户运行；站点只能监听 1024 及以上端口。
- 首次安装 Nginx 版本后自动启用并启动；已有版本仍由用户手动选择启用。
- 增加重启功能；顶部根据运行状态显示启动或停止，停止与重启须确认，校验后可平滑重载配置。
- 管理页优化版本提示、证书通知的上次处理时间，以及手机端服务控制区布局。

### 升级注意

- 从旧的 root 权限包升级时，须确认应用目录、配置、版本和证书文件可由 `nginx_for_fnos` 访问，并将原有低端口监听改为高端口；详见应用使用说明。
- 本机测试和 FPK 打包不替代 fnOS 实机验收；应用权限、网关、Nginx 二进制依赖及 x86/arm 设备行为仍须在目标 NAS 上验证。

## [1.0.0] - 2026-09-29

Nginx for fnOS 首个发布版本。

### 功能

- 在 fnOS 中管理 Nginx：从官方 Debian/Ubuntu 仓库检查、下载并校验稳定版或主线版，按设备架构安装与切换。
- 管理独立的站点配置文件和主配置；保存前运行 `nginx -t`，通过后平滑重载，失败时保留或恢复原配置。
- 支持临时禁用、编辑和重新启用站点，并在重新启用前校验整套配置。
- 支持通过通知文件感知证书更新并重载 Nginx；管理页使用公共通知组件显示操作结果。
- 管理页通过 fnOS 统一网关访问，并限制为管理员操作。

### 修复

- 修正证书通知文件输入框中的路径示例。

### 验证范围

- 本机测试和 FPK 打包不替代 fnOS 实机验收；root 权限安装、网关访问、Nginx 二进制依赖及 x86/arm 设备行为仍需按验收文档验证。
