# Changelog

## [1.1.0]

### Added

- 启用 ANSI/256 色终端显示，提供目录、链接、可执行文件配色、常用 `ls` 别名和彩色提示符。
- 通过应用内置 Shell wrapper 支持 `su` 切换用户后继续使用默认终端配色。

### Changed

- 重排终端工具栏，移除与 fnOS 窗口标题栏重复的应用 Logo 和名称，统一连接按钮文案。

### Documentation

- 增加桌面端和移动端界面预览截图。

## [1.0.1]

### Fixed

- 修复 `vi` 中国旗 emoji 被拆成两个地区指示符、无法正常显示的问题。

## [1.0.0]

### Added

- 在 fnOS 统一网关中提供管理员专用的本机 Bash 终端。
- 使用 xterm.js 和 node-pty，支持中文、交互式程序、窗口缩放、清屏、断开和新建会话。
- 使用一次性 WebSocket 凭据、管理员校验、输出背压和会话进程回收。
- 提供 x86_64 与 ARM64 FPK 构建和原生模块架构校验。
