# Changelog

## [1.2.0]

### Added

- 命令历史按命令实时保存到各用户的 `~/.xterm_history`，断开、关闭窗口或会话被强制回收后重新连接仍可保留。
- 历史去重：重复执行同一命令只保留一条，按一次上箭头即可回到上一条不同命令；启动时自动整理并限制为最近 10000 行。
- 读取 `/etc/environment` 中的 `http_proxy`、`https_proxy`、`all_proxy`、`no_proxy`、`ftp_proxy`（大小写均支持）作为系统代理；会话内系统代理变化无需重连，后续命令即使用新值。
- `su` 切换用户后，命令历史和系统代理继续按目标用户生效。

### Changed

- 历史文件改为每用户独立、权限 0600；应用包用户历史位于 `${TRIM_PKGVAR}/home/.xterm_history`，`su` 后使用目标用户 HOME 下的历史。
- 应用只读取系统代理配置，不修改 `/etc/environment`；不导入 `PATH` 等其他变量。

### Fixed

- 修复会话断开时 PTY 被强制回收、Bash 未写历史导致部分命令丢失的问题。

### Documentation

- 补充命令历史、系统代理和 `su` 行为说明及验收项。

## [1.1.1]

### Added

- 打开终端页面时检查应用自身的 GitHub Release；发现新版本时显示常驻 FPK 下载链接，安装仍由用户在飞牛应用中心手动完成。

### Fixed

- 将应用版本信息打入 FPK 运行目录，避免启动时依赖包外的 manifest。

## [1.1.0]

### Added

- 启用 ANSI/256 色终端显示，提供目录、链接、可执行文件配色、常用 `ls` 别名和彩色提示符。
- 通过应用内置 Shell wrapper 支持 `su` 切换用户后继续使用默认终端配色。

### Changed

- 重排终端工具栏，移除与 fnOS 窗口标题栏重复的应用 Logo 和名称，统一连接按钮文案。

### Documentation

- 增加桌面端和移动端界面预览截图。

## [1.0.1]

### Fixed

- 修复 `vi` 中国旗 emoji 被拆成两个地区指示符、无法正常显示的问题。

## [1.0.0]

### Added

- 在 fnOS 统一网关中提供管理员专用的本机 Bash 终端。
- 使用 xterm.js 和 node-pty，支持中文、交互式程序、窗口缩放、清屏、断开和新建会话。
- 使用一次性 WebSocket 凭据、管理员校验、输出背压和会话进程回收。
- 提供 x86_64 与 ARM64 FPK 构建和原生模块架构校验。
