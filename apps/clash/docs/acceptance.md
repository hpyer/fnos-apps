# 验收清单

本文件区分本机自动测试与 fnOS 实机验收。本机结果不能替代 NAS 验证；以下实机项在完成前均视为未验收。

## 本机自动测试

`pnpm --filter @fnos/clash test` 覆盖：

- `core-versions.lock` 解析、内置 Core SHA256/大小校验、gzip 完整性与 ELF 架构检查。
- 版本渠道解析：MetaCubeX 稳定版、`Prerelease-Alpha` 测试版、vernesong Smart 版资产命名、摘要缺失、来源不在允许名单、GitHub 限流错误映射。
- 校验下载的 SHA256/大小/HTTP 错误/重试清理，以及订阅文本大小限制。
- 配置顶层字段解析、Controller 注入（移除 `external-controller*`/`secret`）、JSON 配置、模式替换和大小限制。
- 配置服务：默认配置、备份/恢复、订阅增删改、掩码、下载内容校验、SSRF 内网与回环地址拒绝。
- 日志脱敏、订阅 URL 掩码、存储原子写入与文件权限。
- mihomo Controller 客户端：Unix Socket 请求、代理切换、延迟测试、连接关闭、流式解析、错误映射。
- 进程与编排（使用测试替身 Core）：启动/停止、健康检查、流量与日志、端口冲突、配置应用失败回滚、订阅应用、版本启用/回滚/删除保护、安装任务互斥、崩溃自动重启、secret 不泄漏、Geo 数据释放。
- HTTP 服务：Socket 权限、管理员头、跨站拒绝、静态资源 CSP、GET/POST 接口、请求体限制、日志与流量 SSE、开发模式 Host 校验；`/api/preparation` 与 `/api/config/template` 的参数校验和分发。
- 准备进度：步骤只前进不回退、未知步骤只更新说明、字节进度、失败标记；首次启动下载外部数据时快照包含活动步骤与 `content-length` 进度。
- 默认配置模板：provider `url` 留空并带「填入你的订阅链接」注释、包含分组和基础规则且能通过结构校验；「载入模板」接口返回同一内容。
- User-Agent：前缀按内核/应用版本生成，后缀默认 `clash.meta; clash`、可清空、拒绝非 ASCII 与超长；订阅、数据、Core 下载与更新检查请求都携带组合后的 UA（含调用方自带 UA 被覆盖）。
- 纯节点订阅：只有 `proxies`（或分组/规则为空）时自动补齐 `proxy-groups` 和 `rules`，完整配置不改写；直接写在 `proxies` 中的节点通过 `/api/proxies` 的 `local` 字段返回。
- 全仓 `pnpm test`、显式 `pnpm run build clash`、`pnpm run pack clash --all` 可重复执行。
- 网络诊断接口返回 allow-lan、bind-address、端口与局域网可达性；GLOBAL 组在规则模式下隐藏、全局模式下显示并提示实际出口；配置编辑器提示被接管的 Controller/secret/log-level/external-ui 和端口字段。
- 设置页的端口、allow-lan 写入运行时配置并重启生效；代理页只展示配置 `proxy-providers`，支持用量/到期/节点数和单提供商刷新。
- GitHub API 限流时版本检查可使用 Atom/资产页面备用来源；备用条目安装时下载后计算 SHA256。
- 服务模式：界面加密密码提权（su 切换登录管理员后执行 sudo）或管理员手工执行一次 `setup-privileges` 把 helper 安装到 `/usr/local/lib/clash-for-fnos` 并写入 sudoers；`core-caps` 为当前 Core 设置 capabilities；系统代理/TUN 成功路径需在目标 NAS 实机验证；权限不足时返回明确错误并回读实际状态。
- 卸载向导默认保留数据；选择删除时只清理本应用 `TRIM_PKGVAR`，并验证保留/删除两条路径。

## 本机已验证（macOS）

最近一次界面检查：2026-11-18。

- 内置 Core 下载、校验、释放到私有目录；管理页在 dev 模式正常加载。
- 界面六页（概览/代理/配置/连接/日志/设置）与侧边栏状态、模式切换渲染；在 1100×596 视口和移动端窄屏检查无横向溢出；概览三列指标；代理节点/策略组可展开（含飞机/指南针图标）；连接列表无横向滚动，点击行查看详情并在详情内关闭；系统代理/增强模式为滑动开关。
- 本机预览正确提示“无法启动 Linux Core”，不会尝试执行 Linux 二进制。
- 首次准备浮动进度卡片在 headless Chrome 中按 1100×596 和 390×844 检查：卡片显示阶段、当前说明、字节百分比和已用时间，可收起，桌面位于右下角、移动端位于底部导航上方，无横向溢出；侧边栏保持原有运行状态。
- 默认模板「载入模板」和代理页「配置节点」在 headless Chrome 按 1100×596 与 390×844 检查：模板载入编辑器并提示填入链接，链接为空时保存前二次确认；配置节点卡片默认收起，点击「展开」显示节点、延迟与数量；纯节点订阅应用后弹出「已自动补充分组和规则」提示；两种尺寸均无横向溢出。
- Clash 测试 87 项全部通过（新增默认模板、配置节点、纯节点订阅补齐与 User-Agent 用例）；workspace 全量测试仅 `apps/xterm` 的真实 PTY 用例因本机环境超时，与 Clash 无关。

## fnOS 实机验收（待执行）

### 安装与生命周期

- [ ] x86_64 与 ARM64 FPK 均可安装、启动、停止、升级、卸载。
- [ ] 首次启动无需外网即可释放并运行内置 Core，代理端口按配置监听。
- [ ] 应用窗口通过统一网关打开，刷新、深链接和普通用户访问限制符合预期。
- [ ] 停止应用后 Core 进程退出；升级后配置、订阅、已安装 Core 保留。
- [ ] 卸载后按 fnOS 约定处理私有数据，不残留运行中的 Core。

### Core 与配置

- [ ] `7890` 等端口被占用时提示明确错误，释放端口后可正常启动。
- [ ] Core 崩溃后按设置自动重启，达到 5 次后停止并在界面提示。
- [ ] 保存非法 YAML、语义错误配置时校验失败且原配置/原 Core 保持运行。
- [ ] 配置应用后连接中断符合预期，旧备份可恢复。
- [ ] 规则、全局、直连模式切换对实际流量生效。
- [ ] 订阅更新后内容正确、地址在界面保持掩码；应用后代理组与节点可用。
- [ ] 清除应用数据后首次启动：右下角浮动进度卡片显示「校验内核 → 准备外部数据 → 校验配置 → 启动内核」，GeoIP/GeoSite（Smart 渠道含模型）下载显示字节或百分比，可收起和重新展开；下载完成后 Core 正常启动。
- [ ] 在配置页保存并应用时复用同一浮动进度卡片，切换页面后进度仍可见，侧边栏只按实际状态显示运行中/启动中/已停止。
- [ ] 首次「校验」或「保存并应用」使用含 GEOIP/GEOSITE 规则的配置时，先补齐外部数据再校验，失败时原配置和 Core 保持不变。
- [ ] 全新安装后默认配置可直接通过 `mihomo -t`；在 provider `url` 中填入机场节点列表链接并保存后，「代理提供商」能加载节点，`节点选择 / 自动选择` 可用。
- [ ] 已有配置点击「载入模板」可载入默认模板且不会自动保存；替换链接后保存生效。
- [ ] 直接添加只含 `proxies` 的节点列表订阅，「应用」后自动出现分组和规则，并提供提示；代理页「配置节点」显示这些节点。
- [ ] 「配置节点」卡片和无策略组提示在 `1100 × 596` 与移动端窄屏下无横向溢出。
- [ ] 设置页 User-Agent 显示系统生成前缀，可编辑自定义后缀；保存后在 NAS 上用抓包或订阅服务器日志确认实际请求携带该 UA；切换内核版本后前缀随之更新。
- [ ] 使用 GEOIP/GEOSITE 规则的配置在无外网 NAS 上能启动（Geo 数据来自 FPK）。
- [ ] 连接列表可筛选、关闭单条和全部连接，代理组切换与延迟测试结果合理。

### 版本管理

- [ ] 检查 MetaCubeX 稳定版、测试版、Smart 渠道版本；限流时提示可理解。
- [ ] 安装新版本校验 SHA256/架构/版本；安装不会自动启用。
- [ ] 启用新版本后重启成功、旧版本保留；故意使用损坏配置时切换失败并恢复旧版本。
- [ ] 回滚到上一版本可用；删除当前版本被阻止；删除后版本目录释放磁盘。
- [ ] `app/cores` 中的内置 Core 在升级后正确切换，旧内置版本目录被清理。

### 网络与资源

- [ ] x86_64 与 ARM64 真实设备上 ELF 可执行、Controller 健康检查通过。
- [ ] 代理端口、DNS、IPv6、局域网访问行为符合配置。
- [ ] 长时间运行内存稳定，日志轮转和 1500 条界面缓存不会无限增长。
- [ ] 管理服务崩溃/被杀后，fnOS 生命周期可重新拉起；Core 不残留。
- [ ] 跨账户访问、文件 ACL、私有目录权限符合 fnOS 预期。

### 安全

- [ ] 普通用户无法访问管理页或调用写接口。
- [ ] 日志、状态、错误信息、页面响应中不出现 Controller secret 或完整订阅 URL。
- [ ] 配置中的 `external-controller` 不会实际监听 TCP 端口。
- [ ] 订阅指向内网地址时被拒绝；HTTPS 证书错误时提示清晰。
